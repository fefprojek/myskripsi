# Projek Website Dinas Kehutanan Jawa Barat

Website ini dibangun menggunakan React JS dengan tampilan yang menyerupai [dishut.jabarprov.go.id](https://dishut.jabarprov.go.id/).

## Struktur Folder

- `fronten/`: Berisi kode React JS untuk tampilan (UI).
- `backend/`: Folder kosong untuk pengerjaan backend di masa mendatang.

## Cara Menjalankan Frontend

1. Masuk ke folder `fronten`: `cd fronten`
2. Install dependensi: `npm install`
3. Jalankan server pengembangan: `npm run dev`

## Teknologi yang Digunakan

- React JS (Vite)
- Tailwind CSS (Styling)
- Lucide React (Icons)
- TypeScript
